# 🎵 Kulturskola – Arbetstids- & Belastningskalkylator

En interaktiv webbapp för att beräkna arbetsbelastning för kulturskolelärare.

## ✨ Funktioner

- Individuell belastningsberäkning per lärare
- Hanterar flera instrument med uppvärmning och övningstid
- Konfigurerbara parametrar
- Visar om tjänsten går ihop eller inte

## 🚀 Användning

1. Fyll i lärarens uppgifter
2. Välj instrument
3. Klicka på "BERÄKNA BELASTNING"
